### 🔍 **Project Title**

**Rice Leaf Disease Detection System Using CNN**

---

### 👨‍💻 **Team Members**

* Dharshana S
* Praveen V
* Vanitha V
* Vijayananth S

---

### 🎯 **Objective**

To develop an **automated deep learning model** using **Convolutional Neural Networks (CNN)** to detect and classify **three major rice leaf diseases** from images:

1. **Bacterial Leaf Blight**
2. **Brown Spot**
3. **Leaf Smut**

---

### 🧠 **Technologies & Concepts Used**

* **Deep Learning (DL)**
* **Convolutional Neural Networks (CNN)**
* **Transfer Learning**

  * **Pre-trained models**: VGG16, ResNet, InceptionV3, Xception
* **Data Augmentation**
* **Keras, TensorFlow, Google Colab**

---

### 🏗️ **System Modules**

1. **Data Collection**
2. **Preprocessing** (resizing, normalization)
3. **Data Augmentation** (rotation, flipping, etc.)
4. **Feature Extraction**
5. **Classification** (using CNN architectures)

---

### 🧪 **Models Compared**

| Model        | Best Performance On          | Accuracy   |
| ------------ | ---------------------------- | ---------- |
| VGG16        | Original Dataset             | Medium     |
| ResNet       | Original Dataset             | Medium     |
| InceptionV3  | Augmented Dataset            | High       |
| **Xception** | **Augmented Dataset (Best)** | **96.67%** |

---

### ✅ **Final Output**

* **Xception** model selected for deployment based on **highest validation accuracy** and **lowest loss**.
* Model predicts disease type from input rice leaf image.

---

### 📈 **Key Benefits**

* High accuracy in early disease detection
* Reduced manual inspection
* Helps farmers take timely actions to minimize crop loss

---

### 🔧 **Future Enhancements**

* Add **multi-spectral image support**
* Improve **user interface** for farmers
* Expand to detect more diseases

---
This project involved developing a deep learning model using Convolutional Neural Networks (CNN) to detect and classify major rice leaf diseases such as leaf blast, bacterial blight, and brown spot. The system utilizes image processing techniques to analyze leaf images and accurately identify the disease type, enabling timely intervention for farmers to manage and mitigate crop losses effectively.
